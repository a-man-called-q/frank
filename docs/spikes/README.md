# Spikes

Open research questions, parked. A spike lives here until it is either answered
— at which point its conclusion moves into `docs/` proper or into code — or
abandoned and deleted.

Nothing here is a commitment, and nothing here is referenced by the build. Do
not treat a checklist in this directory as a plan of record.
